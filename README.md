# Описание проекта

Поисковый движок выполняет индексацию текстовых документов компании, рассчитывает их релевантность на основе частоты встречаемости слов и выдает пользователю наиболее подходящие результаты по его поисковым запросам.

**Основные возможности движка:**
* **Многопоточная индексация:** Быстрый обход и подсчет слов во всех текстовых файлах базы в отдельных потоках.
* **Полнотекстовый поиск:** Нахождение документов, содержащих *все* слова из поискового запроса пользователя (операция логического "И").
* **Ранжирование результатов:** Расчет абсолютной и относительной релевантности документов для точной сортировки выдачи.
* **Гибкая конфигурация:** Настройка путей к файлам, версии и лимитов ответов через JSON.
* **Автоматическое тестирование:** Бизнес-логика полностью покрыта юнит-тестами на Google Test.

# Используемые технологии

* **Язык программирования:** C++ (Стандарт C++17)
* **Система сборки:** CMake (версия 3.14+)
* **Работа с JSON:** Библиотека [nlohmann/json](https://github.com)
* **Юнит-тестирование:** [Google Test (GTest)](https://github.com)
* **Среда разработки (IDE):** VSC/ Qt Creator / MinGW

# Структура

Для работы приложения в корневой папке необходимы три JSON-файла:
1. `config.json` — содержит настройки движка, версию и пути к индексируемым файлам (`files`).
    *Важно: в массиве `files` необходимо вручную перечислять пути к каждому конкретному текстовому файлу, а не к папке целиком.*

2. `requests.json` — содержит список поисковых запросов пользователей.

3. `answers.json` — генерируется автоматически; содержит отсортированные по релевантности результаты поиска.

# Инструкция по сборке и запуску
Убедитесь, что в вашей системе установлены компилятор с поддержкой C++17 (например, GCC/MinGW) и утилита CMake.

## 1. Клонирование репозитория и сборка проекта
Откройте терминал в папке с проектом и выполните следующие команды для сборки:
bash
### Создание папки для сборки
mkdir build
cd build
### Конфигурация проекта с помощью CMake
cmake ..
cmake --build .

## 2. Запуск приложения
После успешной компиляции в папке `build` (или `build/src` в зависимости от ОС) появится исполняемый файл.
Перед запуском убедитесь, что файлы `config.json` и `requests.json` находятся в директории запуска.

Запустите поисковый движок командой:
bash
./search_engine

## 3. Запуск тестов
Чтобы запустить автоматические тесты и проверить корректность работы классов `InvertedIndex` и `SearchServer`, выполните в папке `build` команду:
bash
ctest
